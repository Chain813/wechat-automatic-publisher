## 1. Background & Objectives (Overview & Problem Diagnosis)

### 1.1 Context
In Sub-project 1, the AutoWeChat WebUI management console was successfully overhauled into a modular, zero-build, responsive Linear Modern Light interface adhering strictly to `E:\AI-based-project\408-helper\DESIGN.md`.

In this Sub-project 2, we execute the corresponding transformation for the **core publishing pipeline**:
1. WeChat article inline HTML typesetting generated by `core/shared/article_utils.py`.
2. Selenium/Headless HTML-to-PNG renderer (`utils/html_render.py`).
3. Dual-engine diagram & card generation (`utils/diagram_gen.py`).
4. Pure Python/Matplotlib/Graphviz lightweight card renderer (`utils/lite_render.py`).

### 1.2 Core Pain Points & Diagnostic Review
Previous versions of article generation and diagram rendering relied on dark-slate themes (`#0b0e14`, `#1e293b`, `#111827`) or legacy blue palettes (`#2563eb`), causing several issues:
1. **Visual Disharmony**: The WebUI is now Linear Modern Light, while exported diagrams and formula cards displayed obsidian/dark-slate backgrounds (`#0b0e14`, `#111827`), creating jarring visual contrast when embedded in light-background WeChat articles.
2. **Missing Markdown Table Styling**: `markdown.markdown(..., extensions=["tables"])` outputs raw unstyled `<table>`, `<th>`, `<td>` tags. WeChat's native rich text renderer does not automatically apply modern table borders or padding to unstyled tables, leading to cramped, unbordered, misaligned tables on mobile.
3. **Heavy Dark Code Blocks**: `<pre><code>` used a dark Mac-terminal aesthetic (`#1e293b`) with heavy black shadows (`box-shadow: 0 6px 18px rgba(0,0,0,0.25)`), which clashed with clean light-theme typography.
4. **WeChat Inlining Constraints**: WeChat strictly purges external stylesheet `<link>` tags and `<style>` blocks in published articles. Every typography adjustment, card shadow, border radius, and padding MUST be applied directly via inline `style="..."` attributes without triggering WeChat's strict filtering rules (e.g., maximum length per `<blockquote>` block of 300 characters).

### 1.3 Backward Compatibility Mandate
Existing tests in `tests/test_article_styling.py` establish strict contracts for:
- Callout cards:
  - Warning/pitfall: `#ef4444`, `#fef2f2`, `⚠️`, `避坑指南 / 风险预警`
  - Insight: `#3b82f6`, `#eff6ff`, `💡`, `核心洞察`
  - Action: `#10b981`, `#f0fdf4`, `📌`, `行动清单`
- Diagram-disabled fallback cards:
  - Exact hex codes: `#2563eb`, `#f8fafc`
  - Exact titles: `📊 核心架构与逻辑拆解`, `📊 核心业务流程拆解`, `📊 核心逻辑与架构解析`
- Exact paragraph replacement string:
  `<p style="margin-bottom: 16px; line-height: 1.85; text-align: justify; font-size: 16px; color: #334155;">`
All of these exact assertions must be preserved 100% while upgrading container radii (`10px`), specular highlights, tactile shadows, and typography.

## 2. Design Token System (Linear Modern Light Mapping)

In accordance with `408-helper/DESIGN.md`, the inline typography and card rendering adopt the following token hierarchy:

| Token Role | Hex / Value | WeChat Inline Application |
| :--- | :--- | :--- |
| **Canvas / Sunken Surface** | `#F8F9FB` | Code block background, table header background, blockquote fill |
| **Card Surface** | `#FFFFFF` | Selenium render card `#render-target`, Matplotlib card box |
| **Subtle Inset / Badge** | `#F1F3F7` | Window dot bar top, inline code pill, formula variable box |
| **Accent (Linear Indigo)** | `#4F5BD5` | `<h2>` left bar, `<h3>` text & bar, inline code text, diagram strokes |
| **Accent Glow / Tint** | `rgba(79, 91, 213, 0.08)` | `<h2>` linear-gradient wash, active badge tint |
| **Primary Ink Text** | `#0C0D0E` | `<h2>` text, `<h3>` title, code text, table header text |
| **Body Reading Text** | `#334155` | Paragraphs `<p>`, list items `<li>`, table cell data `<td>` |
| **Muted Metadata Text** | `#5E6470` | Blockquote text, formula notes, caption reading guides |
| **Hairline Border** | `#E2E8F0` / `rgba(0,0,0,0.06)` | Card borders, table grid lines, code card borders |
| **Tactile Shadow** | `0 1px 2px rgba(0,0,0,0.03), 0 4px 16px rgba(15,23,42,0.04)` | Elevated cards, callouts, sunken code cards |
| **Specular Bevel** | `inset 0 1px 0 rgba(255,255,255,1)` | Top edge milled chamfer reflection on code blocks and cards |

## 3. WeChat Inline Typography Specification (`core/shared/article_utils.py`)

### 3.1 Headings (`<h2>` & `<h3>`)
- **`<h2>` (Linear Modern Light Section Header)**:
  ```html
  <h2 style="margin-top: 38px; margin-bottom: 22px; padding: 10px 16px; border-left: 4px solid #4F5BD5; background: linear-gradient(90deg, rgba(79,91,213,0.08) 0%, rgba(248,249,251,0) 100%); border-radius: 6px; font-size: 20px; color: #0C0D0E; font-weight: 700; letter-spacing: -0.01em;">\1</h2>
  ```
  - Upgrades from harsh `#2563eb` 5px bar to milled 4px Linear Indigo (`#4F5BD5`).
  - Gradient seamlessly fades from 8% indigo tint into transparent background.
  - Deep ink color `#0C0D0E` ensures WCAG AAA readability.

- **`<h3>` (Linear Indigo Sub-header)**:
  ```html
  <h3 style="margin-top: 28px; margin-bottom: 16px; font-size: 17px; color: #0C0D0E; font-weight: 600; border-left: 3px solid #4F5BD5; padding-left: 10px;">\1</h3>
  ```
  - Clean 3px Linear Indigo indicator.

### 3.2 Paragraphs & Text Highlights
- **Paragraph `<p>`**:
  ```html
  <p style="margin-bottom: 16px; line-height: 1.85; text-align: justify; font-size: 16px; color: #334155;">
  ```
  - Preserved exactly for backward compatibility with `test_image_placeholder_smooth_elimination_on_failure`.
- **Inline Code `<code>`**:
  ```html
  <code style="background-color: #F1F3F7; padding: 2px 6px; border-radius: 4px; color: #4F5BD5; border: 1px solid rgba(79,91,213,0.15); font-size: 0.92em; font-family: Consolas, Monaco, 'Courier New', monospace;">\1</code>
  ```
- **Strong & Key Highlights**:
  - `<strong>`:
    ```html
    <strong style="color: #0C0D0E; font-weight: 700; background-color: rgba(79,91,213,0.06); padding: 1px 4px; border-radius: 3px;">\1</strong>
    ```
  - `<redbold>` (Key revelation/Aha moment):
    ```html
    <strong style="color: #e11d48; background-color: #ffe4e6; padding: 2px 6px; border-radius: 4px; font-weight: bold; border: 1px solid #fecdd3;">\1</strong>
    ```

### 3.3 Regular Blockquotes & Callout Cards
- **Regular `<blockquote>`**:
  ```html
  <blockquote style="margin: 22px 0; padding: 16px 20px; border: 1px solid rgba(0,0,0,0.06); border-left: 4px solid #4F5BD5; background-color: #F8F9FB; color: #5E6470; border-radius: 8px; font-size: 15px; line-height: 1.75; box-shadow: 0 1px 2px rgba(0,0,0,0.02);">...</blockquote>
  ```
  - Retains >220 character splitting logic to prevent WeChat 300-character quote cutoff.
- **Custom Callouts (`_build_callout_card`)**:
  ```html
  <section style="margin: 22px 0; padding: 16px 20px; background-color: {bg}; border: 1px solid {border_outer}; border-left: 4px solid {b_color}; border-radius: 10px; font-size: 15px; line-height: 1.75; color: #334155; box-shadow: 0 1px 2px rgba(0,0,0,0.03), 0 4px 16px rgba(15,23,42,0.04);">
    <div style="font-size: 14.5px; color: {b_color}; font-weight: bold; margin-bottom: 8px; display: flex; align-items: center; gap: 6px;">
      <span>{use_icon}</span> <span>{use_title}</span>
    </div>
    {body_html}
  </section>
  ```
  - Preserves `#ef4444`/`#fef2f2`, `#3b82f6`/`#eff6ff`, `#10b981`/`#f0fdf4`.
  - Upgrades radius from 8px to 10px and adds Linear multi-layer shadow.
- **Diagram Fallback Cards (`_format_diagram_card`)**:
  ```html
  <section style="margin: 24px 0; padding: 18px 20px; background-color: #f8fafc; border: 1px solid #e2e8f0; border-left: 4px solid #2563eb; border-radius: 10px; box-shadow: 0 1px 2px rgba(0,0,0,0.03), 0 4px 16px rgba(15,23,42,0.04);">
    <div style="font-size: 14.5px; color: #2563eb; font-weight: bold; margin-bottom: 8px; display: flex; align-items: center; gap: 6px;">
      <span>{title}</span>
    </div>
    <div style="font-size: 14px; color: #334155; line-height: 1.75; text-align: justify;">{desc}</div>
  </section>
  ```
  - Preserves exact title strings and `#2563eb` / `#f8fafc`.

### 3.4 Markdown Table Inline Styling
Markdown tables parsed by Python `markdown` with `extensions=["tables"]` emit standard `<table>...</table>`. We post-process tables using regex transformations to inject inline styles:
1. Wrap `<table>` in an overflow protection container:
   `<section style="width: 100%; margin: 22px 0; overflow-x: auto; box-sizing: border-box;">`
2. Style `<table>`:
   `border-collapse: collapse; width: 100%; margin: 0; font-size: 14px; border: 1px solid #E2E8F0; border-radius: 8px; overflow: hidden; background-color: #FFFFFF;`
3. Style `<th>`:
   `background-color: #F8F9FB; color: #0C0D0E; font-weight: 600; padding: 10px 14px; border-bottom: 1px solid #E2E8F0; text-align: left;`
4. Style `<td>`:
   `padding: 10px 14px; border-bottom: 1px solid #F1F3F7; color: #334155; line-height: 1.6;`

### 3.5 Linear Sunken Code Card (`<pre><code>`)
Replaces dark `#1e293b` with Linear Sunken Code Card:
```html
<section style="margin: 22px 0; border: 1px solid #E2E8F0; border-radius: 10px; background-color: #F8F9FB; box-shadow: 0 1px 2px rgba(0,0,0,0.03), inset 0 1px 0 rgba(255,255,255,1); overflow: hidden; display: block;">
  <div style="display: flex; align-items: center; justify-content: space-between; padding: 8px 14px; background-color: #F1F3F7; border-bottom: 1px solid #E2E8F0;">
    <div style="display: flex; align-items: center; gap: 6px;">
      <span style="width: 10px; height: 10px; border-radius: 50%; background: #EF4444; display: inline-block;"></span>
      <span style="width: 10px; height: 10px; border-radius: 50%; background: #F59E0B; display: inline-block;"></span>
      <span style="width: 10px; height: 10px; border-radius: 50%; background: #10B981; display: inline-block;"></span>
    </div>
    <span style="font-size: 11px; font-weight: 600; color: #5E6470; letter-spacing: 0.05em; font-family: -apple-system, BlinkMacSystemFont, sans-serif;">CODE</span>
  </div>
  <pre style="margin: 0; padding: 14px 18px; background-color: #F8F9FB; color: #0C0D0E; font-family: Consolas, Monaco, 'Courier New', monospace; font-size: 13.5px; line-height: 1.65; white-space: pre-wrap; word-break: break-all; border: none; overflow-x: auto; display: block;">{code_content}</pre>
</section>
```
